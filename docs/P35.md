# P35 — Native Mathematical Typesetting, Proof Navigation & Small-Screen Qualification

## Delivered

### Safe offline-capable mathematical typesetting
- Implemented a bounded, dependency-free TeX subset parser with real **native MathML output**. No remote services, extra fonts, DOM injection, or paid mathematics API.
- `\( ... \)` renders inline; `\[ ... \]` and `$$ ... $$` render display math. Ordinary plain text and currency amounts remain literal.
- The supported syntax includes symbols and Greek letters, fractions, roots, subscripts/superscripts, sums, products, integrals, limits, set/logic symbols, `\mathbb{R}`-style number sets, basic text macros and aligned/matrix/cases layouts.
- Unsupported/invalid formulas render their original literal TeX in a visible fallback instead of disappearing or producing deceptive output. A strict token, length and nesting budget bounds parsing.
- Equation rendering now applies to the **question prompt, revealed hints, locked answer, solution rubric, and the learner's optional reading preview**.
- Math is represented as React-native semantic MathML and ordinary escaped text. The parser never uses `dangerouslySetInnerHTML`.

### Useful longer proofs
- The existing structured work+conclusion editor is preserved with its single attempt record, confidence lock, offline queue and draft recovery.
- Added editable notation snippets for fractions, roots, integrals, sums and matrices, containing actual LaTeX delimiters for rendered preview.
- Derived a **proof outline** from the learner's own headings (`Proof`, `Step 1`, `Lemma`, `Claim`, `Case`, `Conclusion`, etc.). Clicking one jumps to the corresponding cursor position in the draft. No new persisted state or duplicate notes index.
- The reading preview now typesets supported mathematics instead of showing only preformatted plaintext. The original source remains editable and is what gets saved.

### Phone and tablet ergonomics
- The focused practice pane uses the full available small-screen width without inherited left-indentation.
- On-screen symbols and math snippets are horizontally scrollable with large touch targets; the textarea uses mobile-friendly input sizing, and grading/confidence buttons remain tap-friendly.
- Wide display equations scroll *inside their equation block* rather than overflowing the page.
- Reading preview retains line breaks; accessibility focus styles and reduced-motion settings remain intact.
- Existing large-screen paper/ink design is preserved; nothing is changed into a generic dashboard.

## Compatibility, guarantees and limits
- The renderer covers a **practical subset**, not the full TeX/LaTeX ecosystem. Unsupported macros stay visible. It is not KaTeX/MathJax, and does not supply arbitrary packages, tagged cross-references, automatic theorem checking, OCR, or handwriting capture.
- MathML is supported in current major browsers, but visual quality and equation accessibility can differ by browser/assistive technology; real device QA remains necessary.
- No external font files, third-party packages, SQL migrations, or new secrets.
- Nothing changes grading credit, source authority, problem scheduling, answer-lock safeguards, active time or draft persistence.
- Native MathML does not make a self-graded mathematical proof independently verified.

## Qualification
- Pure parser tests cover TeX structures, text/math boundaries, unsupported macros, malformed source and input limits.
- Proof-outline regressions cover section detection and cursor offsets.
- GitHub CI checks locked package installation, behavior suite, TypeScript and Next.js build.
- **Not yet qualified:** actual phone/tablet screenshots, screen-reader pass, complex third-party lecture TeX compatibility or live Vercel deployment.
