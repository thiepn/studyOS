## Externally governed human acceptance and rights intake
- `scripts/audit-f15-human.mjs` loads an **original signed F13 witness packet and file bytes**, independent F14 reviewer report and signed signer chronology, plus F15 independently signed, source-backed attestations for (1) physical device/accessibility, (2) source rights, and (3) privacy/two-account negative tests. It uses `auditF14Review` first, then checks the same exact commit and packet digest, source paths including symlink escape, file SHA256, signer trust roots/revocation, distinct roles, and maximum 30-day age.
- Each F15 attestation has: `domain` in `device_accessibility|source_rights|privacy_two_owner`, `head`, `packetSha256`, `actorId`, `keyId`, `observedAt`, `finding` in `observed|blocked|unobserved`, `sourceKind` in `synthetic|external`, relative `path`, lowercase `sha256` and detached `signature`. Ed25519 signs UTF-8 `JSON.stringify(recordWithoutSignature)`.
- The F15 `originals` JSON includes `version:"studyos-f15-v1"`, `head`, `packetSha256`, exactly three `attestations`, and `decisions.prerelease` / `decisions.postrelease` separately signed by distinct actors. Both release custody decisions accept only `hold|request_review` — never claimed `approved`. Each decision includes `role`, `head`, `packetSha256`, `actorId`, `keyId`, `recordedAt`, `decision`, `signature`.
- Externally governed `roots` JSON: `attestations` has exactly three trust roots, and `decisions` has two; each has `status:"trusted"`, matching `role`, `actorId`, `keyId`, PEM Ed25519 `publicKeyPem` and `revokedKeyIds`. Governance and root authenticity must be established independently; placing these fields in JSON does not establish legal or human authority.
- A synthetically generated Ed25519 packet can pass integrity tests but **does not prove** that a real human or physical device actually participated. Even intact externally labeled evidence still requires genuine independent source custody and human approval. Every verifier output is `releaseAllowed:false`, `preRelease:"NO_GO"`, `postRelease:"NO_GO"`, `canRestore:false`, `canPurge:false`.

Run in a separately governed offline environment, supplying all files **from independent custody**, never credentials:

```sh
node scripts/audit-f15-human.mjs \
  --packet /evidence/witness.json --witness-root /custody/witness-root.json \
  --review /evidence/review.json --reviewer-root /custody/reviewer-root.json \
  --custody /custody/chronology.json --custodian-root /custody/custodian-root.json \
  --originals /evidence/real-human-originals.json --human-roots /custody/human-roots.json \
  --files /evidence/original-files --head <EXACT_SOURCE_SHA>
```
