## Detached evidence intake
Run only on a separately controlled review machine with independently sourced `packet.json`, `root.json` and actual source files:

```sh
node scripts/audit-f13-packet.mjs \
  --packet /independent/evidence/packet.json \
  --trust-root /independent/custody/root.json \
  --files /independent/evidence/source-files \
  --head <EXACT_COMMIT_SHA>
```

- The JSON packet contract: `version:"studyos-f13-v1"`, `head`, `originKind:"synthetic"|"external"`, opaque `operatorId`, independent `witnessId`, `keyId`, `issuedAt` in ISO UTC, `artifacts:[{path,sha256}]`, `cases:[{id,result:"passed"|"blocked"|"unobserved",artifact}]`, and a detached-base64 `signature` over UTF-8 `JSON.stringify(packetWithoutSignature)`. Only Ed25519 is supported.
- The externally provided trust-root JSON must contain `status:"trusted"`, matching `keyId` and `witnessId`, `publicKeyPem` and optional `revokedKeyIds`. These external keys and signatures must not be committed with the repository. Independent custody/governance of this root is a separate human-controlled acceptance condition, **not** something the verifier can establish alone.
- Required scenario IDs: `account_desktop`, `account_mobile`, `active_semester`, `course_authorization`, `cross_owner_denial`, `google_grant_separation`, `offline_owner_recovery`, `keyboard_and_screen_reader`.
- The verifier detects path traversal and symlink escapes, mismatched SHA256, invalid/duplicate scenarios, stale issuance, revoked keys and signature tampering. It reports artifact integrity and missing coverage but **always** sets `releaseAllowed:false`. The synthetic test keys are intentionally not a trustworthy real acceptance root.
