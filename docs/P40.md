### Safe deployment verification after a normal quota reset

The repository now includes a read-only verifier. Supply the actual authorized HTTPS host and the **exact SHA** reported by the deployment, not a guessed hostname or whichever commit happens to be latest:

```bash
STUDYOS_DEPLOYMENT_URL=https://<verified-deployment-host>/ \
STUDYOS_EXPECTED_SHA=<exact-40-character-sha> \
npm run qualify:live
```

Checks: live health endpoint, correct package version and Git SHA, accessible StudyOS login, redirect to StudyOS login for anonymous `/setup/platform`, and rejection of an unauthenticated practice write. No real user session, data writes or Google OAuth is performed.

A Vercel-protected preview URL may legitimately give a gateway 401/403; the verifier reports it as unqualified until a properly authorized testing method is available. Never disable deployment protection just to force a green result. Passing the verifier is **anonymous HTTP admission**, not full production/SSO certification.
