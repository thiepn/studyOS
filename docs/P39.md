## Fixed: callback and return-path trust

Previous routes constructed `redirectTo` from request Host and accepted local paths beginning with slash-backslash, which may be interpreted as cross-origin. P39 centralizes safe return-path validation for login and callback. It rejects external, protocol-relative, backslash and encoded-separator paths, auth loops, controls and oversize paths, while preserving legitimate course/week query links.

Google OAuth now uses the canonical `APP_ORIGIN` for the callback and refuses a request made to a different origin. Forced `prompt:select_account` is removed from routine login. This reduces account-chooser friction but **does not prove cross-site SSO**.

Provider settings still require the exact canonical `/auth/callback` URL in Supabase Auth redirect allowlists. Study Drive and Calendar callbacks require separate provider configuration and server-side credentials. See https://supabase.com/docs/guides/auth/server-side and https://supabase.com/docs/guides/auth/redirect-urls.

## New: authenticated pre-semester platform check

The `/setup/platform` page is accessible before the first semester is created, once a THIEPN Account session is authenticated. It reports configuration booleans and the exact callback addresses, but **never the secret values**. Checks include the correct Account project, HTTPS origin, public key, server credential, Drive/Calendar integrations and Git deployment SHA.

It differentiates configuration completeness from live OAuth or academic proof. Direct links are added from the semester-creation and existing-semester setup screens.

## Automated qualification

- Pure tests verify same-origin course deep-link preservation and reject malicious OAuth return paths.
- Pure tests reject wrong Supabase project, localhost production origins and missing server credentials/commit.
- Built-server acceptance tests add unauthorized access to `/setup/platform` and cross-host Google OAuth refusal.
- Existing Node tests, TypeScript, Next.js production build and unauthenticated API tests are mandatory.
