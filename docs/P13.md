# P13 — First-Week Evidence Calibration & Adaptive Practice

## Objective

P12 proved that real Week-1 material can enter StudyOS and produce real attempts. P13 makes those first attempts useful without allowing a tiny sample to distort the semester plan.

The phase adds a guarded calibration layer above the existing evidence engine. It does not create a second mastery model and it does not replace P8 retention, P9 exam intelligence, or P10/P11 workload planning.

## Calibration contract

Only real recorded attempts are used. Independent attempts are the primary calibration sample because they best represent what can be produced without assistance.

Per major course, StudyOS now tracks:

- number of recorded attempts;
- number of independent attempts;
- number of distinct skills sampled;
- independent accuracy;
- confidence-vs-accuracy gap;
- solving pace relative to the question's expected time;
- weakest repeatedly observed evidence dimension;
- recurring error type;
- a conservative recommended question difficulty.

Calibration maturity is deliberately slow:

- **uncalibrated** — fewer than 4 independent attempts or fewer than 2 skills;
- **emerging** — fewer than 8 independent attempts or fewer than 3 skills;
- **usable** — enough evidence to adapt mildly, but not enough to treat the profile as stable;
- **established** — at least 16 independent attempts across at least 4 skills.

The UI asks for roughly 12 independent attempts across 4 skills before first-week calibration is considered sufficiently broad.

## Guardrails against overreaction

Before calibration becomes usable, question selection stays broad:

- sample different skills before repeating one;
- spread evidence dimensions;
- prefer medium difficulty;
- avoid specializing around one early mistake.

Once the sample becomes usable, adaptation remains mild:

- weak dimensions receive a preference, not an exclusive lock;
- difficulty moves only one level down or up from the default;
- confidence gaps can trigger stricter independent answer-locking guidance;
- slow pace can trigger short timed execution work;
- calibration never writes mastery evidence by itself.

The existing attempt engine remains the only authority that changes mastery/retention state.

## Adaptive calibration practice

`/practice` now shows a calibration card for every major course. Each card exposes the evidence sample and links to a bounded calibration set.

`/practice?mode=calibration&course=<course-id>` builds a maximum 20-minute / 5-question set from existing verified questions.

Question ranking favors:

1. unattempted questions;
2. under-sampled skills;
3. under-sampled evidence dimensions;
4. medium difficulty while the course is still uncalibrated;
5. the weakest repeated dimension and calibrated difficulty only after the sample becomes usable.

The session uses the normal ReviewSession attempt recorder, so offline-safe writes, independence tracking, confidence, timing, and error diagnosis continue to work without a parallel data path.

## Progress diagnostics

The Progress page now exposes calibration next to risk and retention diagnostics:

- maturity state;
- independent sample size;
- accuracy;
- confidence gap;
- pace ratio;
- weak dimension;
- recurring error;
- current adaptation recommendation.

This makes early-semester uncertainty visible instead of hiding it behind a premature mastery percentage.

## Non-goals

P13 does not:

- increase the daily study budget;
- fabricate questions or skills;
- infer ability from reading or resource processing;
- let assisted attempts count as independent calibration evidence;
- modify exam strategy from fewer than a usable sample;
- add another external integration.

## Next phase

P14 should turn calibrated Week-1 evidence into a reliable multi-week learning loop: weekly variance detection, workload-vs-performance feedback, and automatic plan correction when a course starts drifting away from expected pace.
