# P17 — Semester Decision Layer, Course-Level Forecasting & Exam Outcome Readiness

## Objective

P17 is the first layer that reasons across the full semester rather than one study mechanism at a time.

It answers three questions:

1. **What is the current evidence-supported readiness state of each course?**
2. **How confident should StudyOS be in that call?**
3. **What single bounded next action has the highest strategic value?**

P17 sits above P8–P16. It does not create another mastery model.

## Important semantics

### Readiness index is not an exam prediction

The 0–100 readiness index is a normalized StudyOS composite of currently available evidence.

It is **not**:

- a predicted exam percentage;
- a probability of passing;
- a German grade prediction;
- a substitute for the actual exam.

This distinction is enforced in the UI.

### Action value is not probability

The 0–100 action-value score is only a ranking device for competing next actions. It expresses relative strategic value from the current evidence.

## Readiness evidence

The readiness model can use:

- syllabus coverage;
- durable mastery;
- exam-ready skill percentage;
- recent independent success;
- P13 calibrated independent accuracy;
- verified P9 timed-paper performance.

When a broadly verified timed paper exists, exam-transfer evidence receives substantially more weight.

P17 then applies bounded adjustments for:

- P8 aggregate course risk;
- P14 sustained drift;
- P15 persistent/structural intervention failure.

P16 response affects trajectory/support interpretation and the next action, but a successful strategy experiment does not magically convert into exam mastery.

## Evidence confidence

Forecast confidence depends on the amount and diversity of evidence:

- mapped/tested skills;
- calibration sample;
- completed-week drift evidence;
- evaluated interventions;
- processed past exams;
- blueprint confidence;
- verified timed-paper evidence;
- P16 method history.

Confidence bands are:

- **very low**
- **low**
- **medium**
- **high**

If evidence is below the minimum reliability threshold, the course is marked **insufficient evidence** and the public readiness index is hidden.

This is intentional: P17 refuses false precision.

## Readiness bands

The internal readiness thresholds are:

- **at risk**: below 50
- **fragile**: 50–64
- **pass-ready**: 65–79
- **target-ready**: 80–89
- **strong**: 90+

These are StudyOS readiness states, not official institutional grade cutoffs.

The high-performance threshold is 80 because this personal StudyOS is optimized for the user's stated goal of roughly 80–90%+ performance where feasible.

## Uncertainty range

Once enough evidence exists, P17 shows a readiness range rather than only a point estimate.

The range narrows as evidence confidence rises:

- very low: ±22
- low: ±16
- medium: ±10
- high: ±6

This range is uncertainty in the StudyOS readiness estimate, not a predicted exam-score interval.

## Trajectory

Trajectory is classified as:

- **unknown**
- **improving**
- **stable**
- **declining**

It is based on longitudinal evidence such as:

- P14 recent accuracy change;
- P15 intervention transfer;
- P16 demonstrated strategy response.

One isolated good attempt cannot create an improving trajectory.

## Exam runway

Time to exam is described separately:

- **ample**: more than 56 days
- **workable**: 22–56 days
- **compressed**: 8–21 days
- **urgent**: 0–7 days
- **passed**: configured exam date has passed
- **unknown**: no exam date

Runway affects decision urgency, not the mastery evidence itself.

## Highest-value next action

P17 generates bounded action candidates, then selects one.

The authority hierarchy remains intact.

### P9 exam mode

Once a course enters transition/exam mode, a concrete P9 exam-strategy action receives the highest authority:

- process exam evidence;
- add another representative past exam;
- baseline timed paper;
- timed paper;
- verify solutions;
- repair exam weaknesses;
- mixed exam practice.

P17 does not replace the exam controller.

### P16 structural-method escalation

Outside exam mode, a persistent/structural P15 course may receive:

- collect clean transfer evidence;
- run the selected P16 method;
- change explanation/source;
- external support.

### P14 drift repair

A non-structural course with sustained repairable drift may receive its bounded P14 correction.

### P13 evidence collection

An evidence-limited course may be told to run calibration before P17 attempts a stronger outcome claim.

### P8 retention / normal coursework

Due retention and actionable workflow gaps remain valid high-value actions.

## Decision priority

Each course gets a 0–100 decision-priority score derived from:

- readiness gap;
- existing P8 risk;
- exam runway;
- declining trajectory;
- structural difficulty;
- evidence insufficiency.

This is used to create the semester decision queue.

It is not a failure probability.

## Semester summary

The Semester Outlook shows:

- credit-weighted readiness across courses with sufficient evidence;
- target-ready / strong courses;
- pass-ready courses;
- fragile courses;
- at-risk courses;
- evidence-limited courses;
- number of high-confidence forecasts;
- highest-priority course/action.

Courses without a reliable readiness index are excluded from the weighted readiness aggregate rather than treated as zero.

## UI

### Semester Outlook

New route: `/outlook`

For every active course it shows:

- readiness band;
- readiness index and uncertainty range;
- evidence confidence;
- trajectory;
- exam runway;
- model components and weights;
- positive supports;
- blockers;
- decision priority;
- highest-value next action;
- action authority and estimated duration.

### Today

Today surfaces the highest-priority P17 semester decision.

This does **not** change the P10 daily plan. P17 ranks strategic value; P10 remains the capacity/scheduling authority.

### Progress

Progress links into the Semester Outlook for cross-course decision analysis.

## Architecture

P17 is derived entirely from existing sources:

- `study_course_risk`;
- `study_courses`;
- `study_exam_strategy`;
- P13 calibration;
- P14 drift;
- P15 intervention validation;
- P16 strategy portfolio.

No new table, view, RLS policy, mastery state, or forecast persistence is introduced.

## Guardrails

P17 must never:

- call its readiness index a predicted exam percentage;
- call action value a probability;
- show a readiness classification when evidence is below the minimum gate;
- let future runway inflate current mastery;
- override P9 once the course is in exam mode;
- override P10 daily capacity;
- convert one successful intervention into a grade claim;
- treat missing data as failure;
- include evidence-limited courses as zero in semester readiness.

## Next phase

P18 should answer counterfactual planning questions safely: with the user's fixed weekly capacity and upcoming exam calendar, how should time be reallocated across courses, what gets sacrificed first, and which allocation gives the best chance of protecting passes while preserving high-performance targets.
