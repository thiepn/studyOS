## Implemented
- One keyboard-first skip link on every route, pointing at a stable, programmatically focusable wrapper immediately before each route's semantic `<main>`. Full-page login retains its own main, without an authenticated navigation leak.
- Shared `Nav` uses a pure URL-to-route-context resolver, contextual Courses/Study/More breadcrumbs, optional exact server-supplied course name and semester title, direct account access and existing StudySyncBridge offline status.
- Desktop primary links retain current route via `aria-current=page` (including subordinate routes). On narrow screens, a native `<details>/<summary>` Browse menu provides keyboard Enter/Space, ArrowDown first-link focus, Escape return-to-summary focus, and closes after navigation. The menu does not require external dependencies.
- Error, loading and not-found routes share a clear accessible status component with explicit retry/return actions.
- Style additions follow the F04 paper, ruled-divider and typography tokens.
- Pure regression tests verify route mappings, native navigation contract, global skip target and shared states. Anonymous built-server smoke continues protecting private endpoints.
- CI Chromium test captures real built-server `/login`, OAuth recovery, and protected `/courses` → login redirect at 1440px desktop and DPR2 390px portrait. SHA256 manifest, not golden replacements.

## Approval caveats
Live session navigation within authenticated pages, real account switching, actual Google consent, physical-device VoiceOver/TalkBack and visual comparisons of private academic routes are **not accepted** by the anonymous CI browser tests. A Playwright dependency is installed only in CI and neither production dependencies nor package locks are changed.
