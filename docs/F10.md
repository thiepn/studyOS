## F10 source changes
- A read-only planning command desk on Today shows urgency and registered deadlines, due-in-48h pressure, daily capacity, uncommitted block suggestions, unscheduled plan items, weekly commitment state and current Calendar evidence.
- Derives deadlines deterministically from already-scoped commitments and an explicit clock; uses existing daily planner output without changing priorities, minute reservations, grades, exam rules, the allocation proposal or any database.
- Accurate Calendar evidence states: disconnected, never synchronized, failed synchronization, unknown result, stale successful snapshot or recent successful snapshot. “Connected” and “not stale” **alone** are never asserted to mean synced or free. Recent refers only to the recorded snapshot, not authoritative live availability.
- External calendar event creation is default-disabled until a successful recent snapshot exists, a source calendar is selected, proposed blocks exist, and the operator explicitly reviews and acknowledges the write. The original server API still requires its own authentication and writable calendar.
- Actual events, proposals, pending placement, unplaceable tasks, unsuccessful partial writes and error states are distinguished. Deletion of an existing Google event gets a separate explicit UI confirmation.
- Weekly rebalance and cancellation require deliberate review. Existing proposed course allocation, original commitment evidence and backend plan rules are untouched. Users can navigate Week allocations and actionable changes directly.
- Academic paper/ink typography, native controls, 44px touch/keyboard targets, forced-colors, reduced-motion, accessible status, no new dependencies, no screenshot-golden modifications.

## Gates and limitations
Exact-head Node tests, TypeScript, production build, HTTP smoke, real Chromium public login screenshots, SHA256 ZIP and individual image manifest must pass. These **cannot** certify authenticated Today/Week/Calendar flows, real Google Calendar OAuth/free-busy/commitment behavior, account-crossing privacy, physical assistive technology, or human owner approval. All remain OPEN. Do not merge/deploy, migrate live data, publish events, provision secrets or call live external calendar endpoints.
