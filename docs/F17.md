## F17 original-source exchange and signer governance
Read-only CLI scripts/audit-f17-exchange.mjs invokes the entire F13→F14→F15 evidence verifier and F16 original-byte custody verifier at the same exact head, using original files provided by independent custody. The F17 packet binds SHA256 of complete F15 originals JSON, complete F16 packet JSON and final signed custody chronology hash. Separate original-file SHA256 and Ed25519 signatures are mandatory for each domain:
- physical_android_pwa
- assistive_technology
- two_owner_privacy
- source_rights

Each evidence record contains role, head, exchangeId, f15Digest, f16Digest, originKind (synthetic/external), finding (observed/blocked/unobserved), sha256, relative path, observedAt, actorId, keyId and signature. An additional two distinct signed HOLD-only decisions for precutover_reviewer and postrelease_reviewer each bind the full evidence list and ledger by a source packet commitment.

F17 packet fields: version = studyos-f17-exchange-v1, head, exchangeId, f15Digest, f16Digest, ledgerHash, evidence [four records], decisions [two HOLD records]. Trust roots JSON holds six independent Ed25519 public roots, one per witness and review role, with role, actorId, keyId, status=trusted, publicKeyPem and revokedKeyIds. Signatures cover UTF-8 JSON.stringify(record without signature). Source packet commitment is SHA256(JSON.stringify({version,head,exchangeId,f15Digest,f16Digest,ledgerHash,evidence})). Verified external labels do not establish actual human/device/source rights authority.

The separate F17 signer ledger has at least one independently custodian-signed event, with head, sequence, previousHash, action, previousKeyId, nextKeyId, custodianKeyId, custodianId, occurredAt, eventHash and signature. Event hash and signature cover JSON excluding eventHash and signature. Actions activate, rotate, revoke and compromise are strictly ordered. Retired/compromised signer keys cannot be reused within the same packet. External ledger roots use role=custodian and the other root properties. Final custody hash binds the F17 exchange packet.

Run on an independently controlled read-only machine:
    node scripts/audit-f17-exchange.mjs --f15 /custody/f15.json --f16 /custody/f16.json --exchange /custody/exchange.json --roots /custody/witness-roots.json --ledger /custody/ledger.json --ledger-roots /custody/ledger-roots.json --files /custody/source-originals --head EXACT_SOURCE_SHA
