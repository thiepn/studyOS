## F12 changes
- Navigation continues to use native responsive `details` menu, active route breadcrumbs and focus-return Escape semantics. Added keyboard-friendly global paths for active semester setup and archived history; route-derived text is only navigation metadata and **never** authorization.
- Login return-path hardening rejects internal `/api`, `/auth`, `/login`, `/_next`, `/_vercel` and `/.well-known` paths, including encoded aliases, path traversal, Unicode/control, malformed percent escapes, protocol-relative and cross-origin return targets. Valid same-origin study pages preserve course filters and page fragments. Redirect authorization remains verified by existing Supabase middleware/callback.
- StudyOS Account includes a separately owner-scoped active semester and active-course count. Both read queries explicitly use the verified Supabase `getUser()` identity. On lookup failure, it defaults to **unverified**, not another semester, stale local browser identity or guessed Google email. Explicit branches for no courses, no semester, historical semesters and active semester give actionable destinations.
- THIEPN sign-out is a deliberate native confirmation; clarifies that Google Drive/Calendar grants are separate and that unsynced offline work cannot be replayed into a different account. Existing sign-out origin verification, same-origin Google switching intent, pending Calendar event blockers and offline replay protection remain unchanged.
- Signed-in no-active-semester and unavailable courses lead to explicit bootstrap/rollover recovery instead of an unhelpful generic workspace failure.
- The global error and not-found states do not claim a failed operation definitely left all data unchanged; they provide Account, Semester Setup and Courses recovery links, without leaking identities or underlying request errors.
- Academic paper/ink navigation with mobile keyboard focus indicators, forced-colors support, no generic cards/gradients; deterministic tests for hostile redirects, account-scoped presentation, recovery and fail-closed offline ownership.
